Privacy Policy

Last updated: 16 September 2026

Who we are

Formula Labs is a YouTube channel run by a single operator. This page covers the website and the software we use to publish videos and read the channel's own statistics ("the fabrica-shorts app").

What the app does

The fabrica-shorts app is an internal tool. It uploads videos to our own YouTube channel and reads our own channel's analytics through the YouTube Data API and the YouTube Analytics API. It is used only by the channel owner. It has no other users and does not access any other person's Google account or data.

Data we access through Google APIs

  • Our own channel's video metadata (titles, descriptions, upload status).
  • Our own channel's analytics (views, watch time, retention, subscribers), in aggregate.

We do not collect, store or share personal data of viewers. We do not sell data. Analytics data obtained from the API is refreshed or deleted within 30 days, in line with the YouTube API Services Developer Policies. Stored data is kept in a private repository accessible only to the operator.

This website

This site is static. It sets no cookies and runs no analytics scripts. It is hosted on GitHub Pages; GitHub may log standard server information such as IP addresses according to its own privacy statement.

Google API Services User Data Policy

Our use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube API Services Terms of Service. You can revoke the app's access at any time in your Google account permissions. YouTube's privacy policy is available at policies.google.com/privacy.

Contact

Questions about this policy: use the contact email on the channel's About page on YouTube.
